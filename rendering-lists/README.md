# 🚀 React From Scratch – Rendering Lists

## 📌 Project Overview

This project demonstrates the concept of **Rendering Lists in React**.

In real-world applications, we often deal with collections of data such as users, products, courses, or messages. Instead of writing repetitive UI manually, React allows us to dynamically render lists using JavaScript.

Rendering Lists helps developers **display dynamic data efficiently using arrays and the `map()` function**, making applications scalable and maintainable.

---

## 🎯 What This Lesson Covers

In this lesson, we explore how to render dynamic lists in React using clean and efficient patterns.

Main ideas covered in this project include:

- Rendering lists using arrays
- Using the `map()` function inside JSX
- Avoiding repetitive code
- Writing clean and maintainable components
- Filtering data before rendering
- Understanding and using `key` properly

## ▶️ How To Run The Project

Install project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

After running the command, open the local development URL in your browser.
