# 🚀 React From Scratch – Event Handling

## 📌 Project Overview

This project demonstrates the concept of **Event Handling in React**.

Modern web applications are not just static pages users constantly interact with buttons, forms, inputs, keyboards, and mouse events.

React provides a clean and powerful way to handle these interactions using **Event Handlers**.

In this lesson, we learn how to make React components interactive by responding to user actions such as clicks, typing, form submissions, and more.

---

## 🎯 What This Lesson Covers

In this lesson, we explore how React handles user interactions using events.

Main ideas covered in this project include:

- Understanding Events in React
- Handling button clicks with `onClick`
- Writing event handler functions
- Using inline event handlers
- Passing functions correctly to events
- Using props inside event handlers
- Accessing the `event` object
- Working with common React events
- Understanding Synthetic Events

---

## 📂 Project Purpose

This repository is part of the **React From Scratch** learning series.

The goal of this project is to demonstrate how developers make React applications interactive using **Event Handling**.

By the end of this lesson, you will understand how to capture user actions and connect them to application logic in a clean and reusable way.

The **full explanation, examples, and walkthrough** are available in the video lesson.

## ▶️ How To Run The Project

Install project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

After running the command, open the local development URL in your browser.
