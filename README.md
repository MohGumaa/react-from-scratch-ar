# 📚 Course Overview

The course is divided into structured phases to help you build strong foundations.

---

## 🔹 Phase 1: Fundamentals

We start by clearly understanding the basics:

- What is React and why do we use it?
- SPA vs MPA
- React vs Vanilla JavaScript
- Create React App vs Vite
- Why Vite is the better modern choice ⚡

---

## 🔹 Phase 2: Core React Basics

Now we move into the heart of React:

- Project Structure
- JSX – HTML inside JavaScript
- Functional Components
- Props & State
- Events & Conditional Rendering

Each lesson will include practical code pushed to the repository so you can follow along step by step.

---

## 🔹 Phase 3: Rendering Data

Here we learn how React handles dynamic data:

- Lists & Keys
- Why using `index` as a key is wrong ❌
- Different Styling approaches in React

---

## 🔹 Phase 4: Forms

Handling user interaction properly:

- Forms in React
- User Input
- Validation
- Best Practices

---

## 🔹 Phase 5: Hooks (🔥 The Real Power)

This is where you level up:

- useEffect
- Fetch API
- useReducer
- useMemo
- useRef
- memo
- Custom Hooks
- Context API

By the end of this phase, you will think like a real React developer.
